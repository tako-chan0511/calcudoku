# ルールと操作方法

- N×Nの各行・各列に1〜Nを重複なく配置します。数独の3×3ブロック制約はありません。
- 太い線で囲まれたケージの数字で左上の計算条件を満たします。
- 加算・乗算は全セルの合計・積です。
- 減算は2セルの大きい値−小さい値です。
- 除算は2セルの大きい値÷小さい値で、割り切れる組合せだけを生成します。
- 1セルのケージは数値固定とし、演算子を表示しません。
- 同一ケージでも、同じ行・列でなければ同じ数字を使えます。

マスをクリック/タップして選択し、キーボードの1〜Nまたは数字パッドで入力します。盤面にフォーカスがある間だけ矢印キーで上下左右に選択を移動し、Delete/Backspaceで削除できます。行の端から次の行へ折り返しません。固定値は選択・確認できますが編集できません。

行・列の重複やケージ条件の矛盾は「!」と説明文で表示します。未完成ケージは、現在の入力から成立する組合せがなくなったときだけ警告します。すべてのマスを埋め、行・列・ケージの全条件を満たすとクリアです。クリア後の数字は編集できません。

最初に数字を書き換えると計測を開始し、クリア時に停止します。「同じ問題で再挑戦」はケージ・問題ID・シードを変えず、入力・選択・警告・タイマーを初期化します。固定値は保持します。Undo/Redoは数字の入力・上書き・削除を取り消し/再実行します。Undo後の新しい変更でRedo履歴を破棄します。固定値・経過時間・答えを見た履歴は巻き戻りません。クリア後は編集とUndo/Redoを禁止します。

「候補表示」は選択セルを置き換える場合の行・列・ケージに基づく候補で、数字を直接入力しません。矛盾がある場合は理由を表示し、候補がなければ「候補なし」と表示します。「答えを見る」は選択セルの正しい数字を入力します。この回はベスト記録の対象外となり、Undoしても使用済み状態は維持します。

この問題のベスト記録は、答えを使わない回の最短時間です。再挑戦で記録を比較できます。途中状態は自動保存し、再読み込み後は検証済みの状態から再開します。閉じていた時間は加算しません。Undo/Redo履歴と選択状態は復元時に初期化します。保存を利用できない場合もプレイできます。

「新しい問題」は設定欄のシード・サイズ・難易度・演算を使い、Workerに生成を依頼します。「ランダムシード」は設定欄のシードだけを更新します。生成中・失敗時も盤面カードは消えず、前の確認済み問題がある場合は保持します。表示するシードは、現在表示している問題のものです。


設定欄は「次の問題」の設定です。サイズ3〜9・難易度・許可演算・シードを選び、「新しい問題」で適用します。編集だけでは現在の盤面を変えません。全演算OFFや不正なシードはエラーにします。選んだ演算が全部登場するとは限りません。減算・整数除算は2マスだけです。

生成中は進行段階とキャンセルを表示します。失敗やキャンセルでは現在の問題を継続できます。9×9は盤面内を横スクロールし、数字パッドで1〜9を入力します。

シードコピーは現在の問題のものです。同じサイズ・難易度・演算子・シード・生成版で再現できます。旧v1のnormalは旧来の生成条件で、v2の解法評価とは分けて表示します。難易度に合う一意解を見つけられない場合は出題しません。


生成方式v3は成功率を改善した最新方式です。旧v1/v2の問題を再現する場合は同じ版を選びます。保存済み問題は自動でv3へ置換しません。

失敗時は「難易度条件」「演算子制限」「探索上限」「試行上限」等を日本語で表示します。別のシード、難易度、許可演算を試せます。設定は自動変更せず、現在の問題と入力・時間・履歴を保持します。

9×9・除算のみ・hardは生成成功が未確認で、動作保証対象外です（固定シードの評価で0/5件）。別の難易度・演算子・シードを試してください。除算のみhardなど、今も指定評価を満たせない条件があります。見つかった一意解がeasy/normalでも、hardとして出題しません。
