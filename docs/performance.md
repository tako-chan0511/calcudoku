## 残る制限

- 3×3 hardは2/50、4×4 hardは44/50。3×3 hardの再現例はシード17・38。固定値や難易度を緩めて成功扱いにはしません。
- 9×9の加算のみnormalは1/5、加減除normalは0/5で、主な失敗理由は探索予算超過。除算のみはこの生成方式・固定値上限・試行上限では各難易度0/5です。数学的に不可能と断定する結果ではありません。
- 演算制限の最大測定時間は約1.40秒。生成はWorkerで行い、キャンセル時は終了して古い応答を破棄します。
- 解法に基づく評価は実装した論理手順を基準とした分類で、人間による難易度校正は今後の課題です。

再実行：`npm run benchmark:matrix -- 50 docs/benchmark-v2.json`。詳細な失敗シード・理由は [benchmark-v2.json](benchmark-v2.json) を参照してください。
